[v0.1.0] - 2026-03-29 - Estructura base del proyecto
----------------------------------------------------

LIMPIEZA
  - Eliminados scripts inconsistentes generados por IA:
    Ant.cs, AntStats.cs, BattleSystem.cs, Skill.cs, GameManager.cs (versión vieja)

NUEVOS ARCHIVOS

  Hormigas/
  - EstadisticasHormiga.cs  : vida, ataque, defensa, velocidad. Métodos RecibirDaño, Curar, EstaViva
  - RolHormiga.cs           : enum con roles Tanque, Luchador, Soporte
  - Hormiga.cs              : clase principal de unidad aliada con nombre, rol, stats y habilidades

  Enemigos/
  - Enemigo.cs              : clase de unidad enemiga con soporte para aturdimiento

  Habilidades/
  - Habilidad.cs            : clase abstracta base con sistema de enfriamiento
  - AtaqueBasico.cs         : ataque sin enfriamiento, disponible para todos los roles
  - GolpeAturdidor.cs       : habilidad del Tanque, 50% de chance de aturdir (CD: 3 turnos)
  - GolpeDoble.cs           : habilidad del Luchador, 10% de chance de golpear dos veces (CD: 2 turnos)
  - Curar.cs                : habilidad del Soporte, cura al aliado con menos vida (CD: 3 turnos)

  Combate/
  - SistemaCombate.cs       : sistema de turnos por velocidad, modo manual y automático
  - FabricaEnemigos.cs      : crea enemigos según escenario (Slimes / Larvas / Arañas)

  Core/
  - GameManager.cs          : Singleton, roster de 6 hormigas (2 por rol), navegación entre escenas

  UI/
  - MenuPrincipalUI.cs      : botones Jugar y Salir
  - MapaUI.cs               : botones para elegir entre 3 escenarios
  - SeleccionUI.cs          : selección de 1 hormiga por rol antes del combate
  - CombateUI.cs            : HUD de combate, botones de habilidades, toggle manual/automático,
                              panel de resultado con botones Siguiente / Repetir / Menú

CORRECCIONES
  - GolpeAturdidor usaba enemigo.Stats.Aturdido (incorrecto), corregido a enemigo.Aturdido
  - FindObjectOfType reemplazado por FindFirstObjectByType (API actualizada en Unity 6)
  - CombateUI.cs tenía problema de escritura en disco, resuelto con script PowerShell externo

ESCENARIOS DEFINIDOS
  - Escenario 1: 3 Slimes   (vida 40, ataque 8,  defensa 2, velocidad 4)
  - Escenario 2: 3 Larvas   (vida 60, ataque 12, defensa 4, velocidad 6)
  - Escenario 3: 3 Arañas   (vida 80, ataque 18, defensa 6, velocidad 10)
